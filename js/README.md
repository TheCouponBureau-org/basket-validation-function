# TCB Basket Validation SDK for JavaScript

This folder contains the standalone Node.js basket-validation SDK package.

Choose the integration guide that matches your application:

- [Standard API-only integration](Readme.JavaScript.md)
- [Optional local offer-store integration](ReadmeWithLocalDatabase.JavaScript.md)

## Validate the package

```bash
npm test
npm pack
```

The generated package can be installed directly into a Node.js 18+ project.
